# Helena Design

Sitio boutique responsive para Helena Design, con catálogo, carrito local, visor GLB y prueba virtual experimental mediante cámara y MediaPipe Pose.

## Publicación
Sitio estático compatible con GitHub Pages. La cámara requiere HTTPS.

## AR
La prueba virtual detecta hombros y torso en el navegador. El GLB incluido es aproximado porque se construyó desde una única referencia visual; para un modelo comercial fiel se requieren múltiples fotografías o escaneo 3D.

## Comercio
El carrito funciona localmente. El checkout real requiere credenciales de un proveedor como Mercado Pago, Webpay, Shopify o Jumpseller.
